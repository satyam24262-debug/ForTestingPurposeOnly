# Security Policy

## Supported Versions
We provide security updates only for actively maintained versions:

| Version | Supported |
|---------|-----------|
| 5.1.x   | ✅ |
| 5.0.x   | ❌ |
| 4.0.x   | ✅ |
| < 4.0   | ❌ |

## Reporting a Vulnerability
If you discover a security issue, please report it responsibly:

- Use GitHub’s **Security → Report a vulnerability** option to open a private advisory.
- Alternatively, email us at **security@example.com** (replace with your contact).
- We will acknowledge your report within **48 hours**.
- Updates will be provided weekly until resolution.
- If accepted, a patch release will be issued and a CVE disclosed.

## Disclosure Policy
- Vulnerabilities will be disclosed publicly only after a fix is released.
- Critical issues may trigger an immediate patch release.
- Non‑critical issues will be scheduled in the next minor release.

## Scope
- This policy applies to all code in this repository.
- Third‑party dependencies are handled via Dependabot alerts.

## Timeline
- Acknowledgement: within 48 hours.
- Initial assessment: within 7 days.
- Fix release: typically within 30 days, depending on severity.
